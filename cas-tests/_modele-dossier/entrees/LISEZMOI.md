Déposer ici (données anonymisées uniquement) :
- `lettre-mission.md` (ou .pdf / .docx) : la demande du mandant ;
- `pieces-communiquees.md` : la liste exhaustive des pièces et les informations qu'elles contiennent (titre, copropriété, PLU, diagnostics, bail) ;
- `notes-visite.md` : les notes brutes de l'expert, telles quelles, avec ses estimations de travaux ;
- `comparables-dvf.csv` : le tableau des comparables exporté (DVF, PERVAL…), avec la source de chaque colonne ;
- `photos/` : les photos, légendées dans le nom du fichier ;
- facultatif : `profil-expert.md` (voix, synthèse en tête, textes standard) ;
- en phase 2 : `arbitrage-expert.md` rempli par l'expert.
