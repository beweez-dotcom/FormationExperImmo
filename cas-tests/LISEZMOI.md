# Cas de test

Un dossier par cas. Pour en créer un, copier `_modele-dossier/` et le renommer (ex. `amiable-t3-paris11`).

- `entrees/` : ce que l'expert fournit (lettre de mission, notes de visite, photos dans `photos/`).
- `sorties/` : ce que les agents produisent (fiche-mission, collecte, description, projet-rapport, controle).
