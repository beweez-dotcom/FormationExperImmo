# FormationExperImmo

Projet d'équipe d'agents IA qui prépare les rapports d'expertise immobilière.

## Pour s'y retrouver

- **CLAUDE.md** : la mémoire du projet. Claude Code la lit à chaque séance.
- **memoire/** : le journal des décisions et l'état d'avancement.
- **.claude/agents/** : les 5 agents (mission, collecte, visite, rédacteur, contrôleur).
- **.claude/skills/** : les savoir-faire partagés (plan type, Charte, style, données, RGPD).
- **sources/** : les rapports modèles et les supports de formation.
- **cas-tests/** : les dossiers sur lesquels on fait travailler l'équipe.
- **app/** : l'interface de démonstration (plus tard).

Le dossier `.claude` peut être masqué dans l'explorateur Windows : menu Affichage > Afficher > Éléments masqués.

## Pour lancer l'équipe

Ouvrir ce dossier dans Claude Code et demander : « Prépare le rapport du dossier cas-tests/<nom-du-cas> ».
