# Interface de démonstration

- `demo/index.html` : la page publiée (« Expertise augmentée »). Elle contient les sorties réelles de l'essai du 26/10/2026 sur le cas rue Keller ; l'animation rejoue la chaîne, l'arbitrage de l'expert et le contrôle sont recalculés en direct.
- `demo/modele.html` : le modèle de la page. Pour mettre à jour la page après un nouvel essai, réinjecter les fichiers de `cas-tests/amiable-t3-keller/sorties/` à la place de `__DOCS__`.
